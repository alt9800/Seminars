第四章 さまざまな立体表現（1）

MapLibre GL JS で「押し出し」と「GLBモデル」を扱う

平面の形に高さを与える

建物の輪郭（フットプリント）は、地図の上ではただの多角形です。これに「高さ」という属性を掛けて上に伸ばすと、箱型の立体になります。これを押し出し（extrusion）と呼びます。

ここでは OpenStreetMap の建物を使っています。高さが登録されている建物はその値、階数だけの建物は階数から換算した値、何もない建物は仮の値で伸ばしています。

色は高さで塗り分け
0 m20 m60 m150 m 以上

建物をクリックすると、使われている高さの値を表示します。

押し出しで作れるのは「底面と天井が平らな箱」までです。屋根の傾きや、上に行くほど細くなる形は表せません。これを表すには、形そのものを3Dデータとして持つ必要があります（次のタブ）。
コード：押し出しのレイヤー 
map.addLayer({
  id: 'bldg-3d',
  type: 'fill-extrusion',          // 押し出し
  source: 'omt',
  'source-layer': 'building',
  paint: {
    // 高さ（m）。属性 render_height に倍率を掛ける
    'fill-extrusion-height':
      ['*', ['coalesce', ['get', 'render_height'], 5], 1.0],
    // 底面の高さ（ピロティなど、浮いた建物部分）
    'fill-extrusion-base':
      ['*', ['coalesce', ['get', 'render_min_height'], 0], 1.0],
    // 高さで色を変える
    'fill-extrusion-color': ['interpolate', ['linear'],
      ['coalesce', ['get', 'render_height'], 5],
      0, '#e9e2d2', 20, '#d9a36a', 60, '#b5553c', 150, '#5b2a4e'],
    'fill-extrusion-opacity': 0.9
  }
});
補足：PLATEAUの建物を押し出しで使わない理由
PLATEAU配信サービスでは、立体の形を持つ建築物モデルは 3D Tiles として配信されています（MVTで配信されるのは、もともと高さを持たない平面のデータが中心です）。押し出しで再現するより、元の立体をそのまま読むほうが情報を失いません。この話は次のページ（CesiumJS）で扱います。

3Dモデル（GLB）を地図に置く

glTF は Khronos Group が定めた3Dモデルの形式で、GLB はそれを1つのファイルにまとめたものです。形・色・テクスチャ・アニメーションを1ファイルで持てるため、Webで扱いやすい形式です。

MapLibre は GLB を直接は読めないので、3D描画ライブラリの three.js を「カスタムレイヤー」として地図に差し込み、同じ画面に描いています。

アニメーション
GLBの中の座標は「モデルの中心からの距離」で、緯度経度は入っていません。そのため、地図に置くときはどこに・どの向きで・どの大きさで置くかをこちらで決める必要があります。大きな範囲を正しい位置で扱いたいときは、位置情報を持てる 3D Tiles を使います。
コード：three.js をカスタムレイヤーとして重ねる 
const layer = {
  id: 'glb-model',
  type: 'custom',
  renderingMode: '3d',   // 地図と奥行き（深度）を共有する
  onAdd(map, gl) {
    this.camera = new THREE.Camera();
    this.scene = new THREE.Scene();
    // MapLibre と同じ WebGL の描画先を使う
    this.renderer = new THREE.WebGLRenderer({
      canvas: map.getCanvas(), context: gl, antialias: true
    });
    this.renderer.autoClear = false;
  },
  render(gl, args) {
    // 置きたい緯度経度・高さを、地図の内部座標に変換
    const mc = maplibregl.MercatorCoordinate
      .fromLngLat([lng, lat], baseHeight);
    const s = mc.meterInMercatorCoordinateUnits(); // 1mの長さ
    const local = new THREE.Matrix4()
      .makeTranslation(mc.x, mc.y, mc.z)
      .scale(new THREE.Vector3(s, -s, s))
      .multiply(new THREE.Matrix4().makeRotationX(Math.PI / 2)); // glTFはY軸が上
    const m = new THREE.Matrix4()
      .fromArray(args.defaultProjectionData.mainMatrix);
    this.camera.projectionMatrix = m.multiply(local);
    this.renderer.resetState();
    this.renderer.render(this.scene, this.camera);
    map.triggerRepaint();
  }
};
map.addLayer(layer);
コード：GLBを読み込む（URL・ドロップ） 
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
const loader = new GLTFLoader();

// URLから
loader.load('model.glb', (gltf) => scene.add(gltf.scene));

// ドロップされたファイルから
const buf = await file.arrayBuffer();
loader.parse(buf, '', (gltf) => scene.add(gltf.scene));
補足：PLATEAUの建物をGLBにするには
PLATEAUの元データは CityGML です。PLATEAU GIS Converter を使うと glTF などに変換できます。変換したGLBの原点や向きは出力設定によって変わるので、このページでは「1単位を1mとして扱う」にしたうえで、位置と向きを手で合わせてください。
