第四章 点群（LAS）を地図に置く

deck.gl の PointCloudLayer で、LASファイルをブラウザだけで読む

点群とは

レーザ測量や写真測量で得た「位置（と色）を持つ点」の集まりです。DEMのように決まった間隔で並んでいるわけではなく、レーザや写真が捉えた場所ごとに点があります。

LAS は点群の代表的なファイル形式です。先頭のヘッダに点の数・座標の倍率・範囲などが書かれ、その後に点が同じ長さの記録として並んでいます。このページでは、その中身をJavaScriptで直接読んでいます。

ヘッダの座標参照系（EPSGコード）が分かれば自動で入ります。分からないときは手で入れてください。

緯度 経度
点の座標は、点群の中心からの東西・南北の距離（m）として地図に置いています。UTMや平面直角座標の値は真の距離とわずかに異なりますが、数mの範囲ではその差は見えません。高さの値が楕円体高か標高かは、ファイルによって違います。
コード：LASのヘッダと点を読む 
const dv = new DataView(buf);
const offsetToPoints = dv.getUint32(96, true);
const format = dv.getUint8(104) & 0x3f;   // 点の記録形式
const recordLength = dv.getUint16(105, true);
const count = dv.getUint32(107, true);
const scale  = [dv.getFloat64(131, true), dv.getFloat64(139, true), dv.getFloat64(147, true)];
const offset = [dv.getFloat64(155, true), dv.getFloat64(163, true), dv.getFloat64(171, true)];

for (let i = 0; i < count; i++) {
  const p = offsetToPoints + i * recordLength;
  // 座標は整数で入っていて、倍率と原点で実際の値に戻す
  const x = dv.getInt32(p, true)     * scale[0] + offset[0];
  const y = dv.getInt32(p + 4, true) * scale[1] + offset[1];
  const z = dv.getInt32(p + 8, true) * scale[2] + offset[2];
}
コード：deck.gl で点として描く 
const layer = new deck.PointCloudLayer({
  id: 'las',
  data: { length: n, attributes: {
    getPosition: { value: positions, size: 3 },  // Float32Array
    getColor:    { value: colors,    size: 3 }   // Uint8Array
  }},
  coordinateSystem: deck.COORDINATE_SYSTEM.METER_OFFSETS,
  coordinateOrigin: [lng, lat, 0],  // ここを中心に、m単位で置く
  pointSize: 2
});
const overlay = new deck.MapboxOverlay({ layers: [layer] });
map.addControl(overlay);
